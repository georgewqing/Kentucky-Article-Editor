# 游戏关卡节奏

WHEN：关卡流程、教学、压力曲线、遭遇节奏。不要在这里写战斗公式（`/game-numbers`）或整段电影剧本（`/game-narrative`）。

## 落盘

- `design/levels/<关卡id>.md`
- 结构建议：教学目标 → 空间/动线（可用文字或导图）→ 教 / 试 / 变 → 奖励与失败 → 时长估计（标假设）

## 与分镜

- 工作区若有 `.kyboard`，用**镜号 / 稿本名**引用，不要空谈「镜头推近」却不指向文件。
- 没有分镜就写文字节拍，并建议用户开分镜头稿本。

## 规则

- 第一关必须写清「玩家学会哪一个动词」。
- 先读 `design/gdd.md` 与核心系统文档。
- 难度数字若出现，必须能指到 `design/balance/*.csv`。

## 禁止

- 把关卡写成与 GDD 核心循环无关的电影过场清单
- 发明未在系统文档出现的机制
