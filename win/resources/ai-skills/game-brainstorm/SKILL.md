# 游戏创意砍刀

WHEN：用户要聊玩法点子、卖点、砍范围、对标、或「这游戏是什么」。不要用来填完整 GDD（用 `/game-gdd`）或写 Steam 页（用 `/game-store`）。

## 落盘

- 只写 **`design/concept.md`**（未升格）。不要覆盖 `design/gdd.md`。
- 升格进活 GDD 由用户挂 `/game-gdd` 再说。
- 若已有 `concept.md`，先 `read_file` 再改，保留用户已砍掉的范围。

## 必须产出

1. 一句话卖点（谁、在哪、做什么、为何有趣）
2. 核心循环（玩家 30 秒内重复的动作 → 反馈）
3. 非目标：明确不做什么（范围砍刀）
4. 参考动机（MDA / 玩家幻想一句即可，勿课堂作文）
5. 风险：最大不确定的手感/系统，标 `[待确认]`

## 禁止

- 复刻现成 IP 的系统当「致敬」
- 发明未验证的具体数值（交给 `/game-numbers`，并标待原型验证）
- 一轮写成可发行 GDD
